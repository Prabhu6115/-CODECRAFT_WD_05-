Weather Web App

A simple and interactive web application that fetches and displays real-time weather information using the OpenWeatherMap API. Users can input a city name to view the current weather conditions, including temperature, humidity, and weather description.

Features

Search weather by city name

Displays temperature, humidity, and weather description

Clean and responsive UI

Error handling for invalid city names


Technologies Used

HTML – Structure of the webpage

CSS – Styling and layout

JavaScript – Fetching and displaying weather data

OpenWeatherMap API – Weather data source


Getting Started

1. Clone the repository

2. Get a free API key

Sign up at OpenWeatherMap and get your API key.

3. Replace YOUR_API_KEY

In script.js, replace the placeholder:

const apiKey = "YOUR_API_KEY";

4. Run the app

Open index.html in your browser.
